# Forgejo k8 logo

This directory contains variations of Forgejo logo with a "k8" label added to it. It is used to represent the Forgejo Kubernetes cluster.

[Forgejo logo](../../#logo) is made by Caesar Schinas and licensed under the [CC BY-SA 4.0 license](https://creativecommons.org/licenses/by-sa/4.0/).

The label uses the [Inter 4.0](https://github.com/rsms/inter/releases/tag/v4.0) font, bold and vertically scaled by a factor of 1.25. Inter is licensed under the [SIL Open Font License 1.1](./inter-license.txt).
